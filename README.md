# ademolaadeagbo.com.ng

Portfolio of Ademola Peter Adeagbo. Static site in `site/`, deployed to the Cloudflare Worker `steep-darkness-fcc1`.

Every push to `main` builds and deploys automatically (Cloudflare Workers Builds, `npx wrangler deploy`).

Also mirrored on Vercel (project `ademola-adeagbo`, root `site/`), deployed on every push to `main`.
